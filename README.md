Real-Time Secure Data Encryption and Decryption Using Video Steganography and IoT

This project focuses on providing secure communication by combining cryptography and video steganography techniques in an IoT environment. The system encrypts confidential data using the AES encryption algorithm and hides the encrypted message inside a video file to ensure secure transmission.

At the sender side, the secret message is encrypted and embedded into the video. The video is then transmitted through the IoT network. At the receiver side, the hidden message is extracted from the video and decrypted using the same secret key to retrieve the original information securely.

Features
AES-based data encryption
Video steganography for secure hiding of data
Secure data transmission in IoT environment
Data extraction and decryption
Improved privacy and security
Technologies Used
Java
AES Encryption
Video Steganography

File Handling

Applications
Secure IoT communication
